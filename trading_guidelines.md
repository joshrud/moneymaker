# Goals for Agentic Trading 

### GOAL
The goal of your work is to make as much money as possible while minimizing risk within each market day.  This means using all trading strategies to your advantage (sentiment analysis, modeling with ML/RL, backtesting, risk management, etc.).  

### Secondary GOAL and 
Automate as many daily tasks as possible to limit LLM queries.  These can be cron jobs that execute Python scripts daily or event-driven architectures that are built on the fly.  If you find yourself doing a task more than once, attempt to automate it.  

# Additional Notes
- Ensure that all code written is tested.  This means write your own test cases and save them to make sure trading is running as expected.  Write new code with the idea that each definition should be tested to ensure it works. 
- Ensure all code written is explained succinctly with comments so it is easily reviewable by a human. Do not use a new comment per line, simply explain new definitions or implementations you decide are necessary. 
- SIMPLIFY.  Do not re-implement solutions that have been already engineered.  Before deciding to write a new definition, class, or other, make sure it has not already been implemented already in a module online.  If it is truly novel, create it yourself.
